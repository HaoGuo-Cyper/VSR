## 完成范围和公平性

B 为原 flow-matching 基线，R 为相同流程加 VideoMAEv2 关系监督，固定 λ=0.5、margin=0.1。两臂从同一个已经训练 8192 步的 NoRef Base01 开始，分别再训练 2048 步，共 **4096 正式更新、0.5 RE**。本轮没有权重搜索、没有最佳中间检查点选择；验证完成后锁定两臂最终 2048 步，并全部测试。

- 训练种子 20261102；有效 batch 1；每臂全新 AdamW、constant LR、相同更新范围和数据/噪声/时间步序列。没有 EMA。
- 8 个检查点：每臂 512/1024/1536/2048；1536 只用于状态审计，不是质量评价点。
- 验证 448 次恢复：shared0 + 两臂 × 512/1024/2048，共 7 roles × 32 clips × 2 sampler seeds。
- 测试 128 次恢复：两臂最终 2048 × 32 clips × 2 sampler seeds。合计 **576 次恢复、19,008 张预测 PNG、576 段 MP4**；每次完整输出声明的 33 帧 128×224 窗口，不代表原始长视频全长或原分辨率。
- Native verify 已核完整媒体、模型和来源链。独立统计复核重新计算全部 576 行、288 个种子平均后的 clip-role、50 组均值/SD、25 个配对区间，与正式分析一致；不重复加载大型 checkpoint tensor，其内容 SHA 依赖紧邻 native verify，另独立核路径/大小/元数据和全部文本、指标 SHA。
- 训练审计：2048 对数据/σ/时间步逐条一致；四条显式 RNG 流在四个检查点逐字节一致；8 个检查点中的 488 个学生可训练张量均更新；R 的 4 个检查点中 6 个头张量均更新且 AdamW 二阶矩非零。教师冻结，2048 次在线前向、0 教师参数更新，诊断标志为空。

相关CPU与TinyWan回归、真实GPU预飞均已通过：15/15目标案例的学生辅助梯度为正，覆盖三个噪声档；26诊断更新、31教师前向、30VJP按预算完整记录。零权重基线逐步精确、教师重复特征一致、学生原生加载和学生/head/AdamW/四显式及全局RNG完整恢复通过；预飞参数没有复用于正式训练。核心仍为10个业务Python文件加包入口，主要变更位于teacher/losses/data/train/checkpoints/evaluate，旧轮代码和结果保留。

## 最终测试：五指标与配对区间

先在每个 clip 内平均 sampler42/43，再对 32 个源视频片段等权汇总。SD 是 **clip sample SD（ddof=1）**，不是训练种子 SD。配对区间采用 10,000 次 paired-clip bootstrap、NumPy PCG64 seed20261102、95% linear-percentile；它们是单训练种子条件下的描述性区间，没有 p 值，不代表多种子显著性。

差值统一为正值有利 R：LPIPS、tLP100、tOF 用 B−R，PSNR、SSIM 用 R−B。主要质量指标为 LPIPS；未追加历史 G4 或 temporal AND gate。

| 指标 | B：均值 ± clip SD | R：均值 ± clip SD | 配对差（正值有利 R） | 95% 描述区间 |
| --- | ---: | ---: | ---: | --- |
| LPIPS ↓ | 0.114820 ± 0.037786 | 0.115637 ± 0.039283 | B−R -0.000817 | [-0.002602, +0.000784] |
| PSNR/dB ↑ | 22.688752 ± 2.210994 | 22.587840 ± 2.199926 | R−B -0.100913 | [-0.132218, -0.069982] |
| SSIM ↑ | 0.698868 ± 0.092031 | 0.693865 ± 0.094131 | R−B -0.005003 | [-0.006176, -0.003879] |
| tLP100 ↓ | 0.374652 ± 0.267397 | 0.383626 ± 0.282687 | B−R -0.008974 | [-0.022598, +0.001715] |
| tOF ↓ | 0.240373 ± 0.320291 | 0.228034 ± 0.257061 | B−R +0.012339 | [-0.004193, +0.043154] |

LPIPS 点估计略差且区间跨零，应判为**证据不足**。PSNR 下降约 0.101 dB、SSIM 下降约 0.0050，条件描述区间均在零以下。tLP100 点估计变差、tOF 点估计改善，但两个区间都跨零，不能声称稳定时间一致性收益。

时间指标沿用仓库已封存的TecoGAN定义：33帧去前后各2帧后保留帧2..30的28个相邻对；tLP100=100×mean|LPIPS(HR前后帧)−LPIPS(SR前后帧)|，tOF为同规则空间crop内的Farneback光流差L2均值。它们衡量相对HR的变化误差，不能只凭更平滑宣称更好；从原量化PNG等价像素计算，不从有损MP4计分。

完整数据：[测试逐片段五指标](analysis/test/per_clip_metrics.csv)；[测试逐片段配对差](analysis/test/paired_clip_differences.csv)；[测试汇总](analysis/test/summary.csv)；[测试配对区间](analysis/test/paired_summary.csv)；[测试分析 JSON](analysis/test/analysis.json)。

## 原方法保留与 Wan 适配

保留 VideoREPA 的 **VideoMAEv2-B 教师、三层 MLP、one-based 第18层、λ0.5、margin0.1 和官方代码全 token Gram 目标**。教师冻结、eval/no-grad、FP32 在线前向，没有改成 Wan frozen/EMA 教师。官方权重严格匹配 158 个 encoder keys、86,225,664 参数，显式排除 4 个分类相关张量。权重 SHA：`8141a6955e0700d11bf15928fe6d61e5cfe482606fed8cfdddb1b922c0fd88ec`。

| 项目 | 本轮实现及适配差异 |
| --- | --- |
| 学生 | Wan2.1-T2V-1.3B，LoRA8 + LR 残差支路，从已训练 Base 续训；不是原 CogVideoX 训练配置 |
| 抽取层/头 | zero-based block17；1536→2048→2048→768，两次 SiLU；Wan 和 CogVideoX-2B 均 30 blocks，约60%深度 |
| HR 教师输入 | 相同 HR33×128×224 区域，去首帧后32帧；[0,1] 输入做 ImageNet 归一化，无额外 resize/crop；tubelet2/patch16→16×8×14 |
| 学生网格 | 全9 latent先逐token MLP，再去首至8，时间插值到16；空间已8×14，因此省去原stride3空间卷积 |
| 原公开代码尺度 | HR49×480×720→去首48→160×240→24×10×15；本轮窗口、裁剪和 token 数不同 |
| 位置编码 | 原固定 sin/cos 构造，再按原顺序做空间和时间插值到目标网格，不新增可学位置参数 |
| 精度 | 学生投影/归一化/Gram bf16，教师/目标 Gram FP32；差值、abs、hinge、mean FP32；normalize eps1e-12 |
| 关系归约 | 沿用官方 full ordered-pair Gram mean；本轮为1792×1792（含对角），不是论文空间/时间两项分别平均；本轮同时间对1/16，跨时间对15/16 |

时间插值是网格适配；Wan 因果 VAE 与 VideoMAEv2 tubelet/全局注意力感受野不同，不能声称 token 感受野严格一致。小裁剪、LoRA8、2048步是资源和探索预算选择，不是原方法必要条件。采用完整监督配置后的效果，不能只归因于教师表示本身。

## 局限和后续建议（未执行）

单训练种子、32测试源片段和小裁剪限制泛化。沿用事前清理的 train1641/val32/test32 源视频隔离清单；近重复筛查不穷尽所有转码、偏移、裁剪变体。测试来源和像素在历史研究中使用过，属于 **source-heldout 探索性测试，不是 pristine/blind**。与旧 VAE/DINO/Wan-EMA 轮次的层、头、损失等不同，不能将跨轮数值当作仅改变教师的因果比较。

当前不建议直接将这组设置扩成“确认收益”的多种子正式研究，因为尚无正向最终收益。若继续，优先前瞻固定一个针对性对照，例如降低辅助权重，或比较全 Gram 与空间/时间分别归约；保持同初始化、数据噪声、预算和完整基线，并锁定新的评价规则。两类调整对应不同问题，不宜同时改动后无法归因。噪声诊断能指导设计，不能在本轮分数后静默改原协议。更接近论文的大窗口/更广参数更新范围需要另行资源预算与更独立数据；本轮不证明放大必然有效。此处仅建议，没有启动后续实验。
