本项目基于 Wan2.1 T2V，研究共享视觉结构对齐与跨帧关系监督，是否能够改善条件视频超分辨率。请按照以下方案建立独立实验工程，并从新的训练记录开始实施。

**实验目标与任务定义。**

最终模型支持两种输入：

- LRV＋caption → HRV。
- LRV＋caption＋一张 HRI → HRV。

LRV 是低分辨率视频；HRV 是对应的高清目标视频；HRI 是同一视频中某一时刻的高清参考帧。首版要求知道 HRI 对应的帧索引。输出保持输入视频的时间顺序、帧数和帧率，主要提升空间分辨率与恢复质量。

训练使用配对 LRV、HRV 和 caption。HRI 从训练 HRV 中抽取。推理时只能读取用户提供的 LRV、caption 和可选 HRI，不能读取其他 HRV 真值。

本轮要验证三个研究假设：

1. HR 教师表征监督能够改善 Wan 视频超分的恢复质量或训练效率。
2. 根据运动与可见性建立的跨帧关系监督，能够进一步改善时间一致性，同时保持内容与细节。
3. 可选 HRI 能够改善非参考帧的恢复质量，模型在没有 HRI 时仍能正常工作。

首版采用**共享视觉结构对齐空间**。caption 继续通过 Wan 原生文本条件通路参与生成。当前不声称文本、视频和参考图像已经形成严格同胚或完全信息等价的 universal space。

**全新实验的边界。**

允许使用指定版本的官方预训练 Wan、Wan-VAE、UMT5、DINOv2 和光流模型权重。

不得加载此前项目的微调 checkpoint、LoRA、任务适配器、优化器状态、训练调度器状态，或将此前生成结果纳入新实验评价。原始数据和可验证来源的官方权重可以继续使用。

新建独立实验目录、配置、日志和输出目录；保留原有文件，不删除旧实验。所有正式对照从相同官方模型版本独立初始化。这里的“逐步增加模块”指实现顺序，不代表后一个对照可以额外继承前一个对照的训练时间。

每次实验记录代码版本、权重来源、配置、随机种子、数据划分和训练预算。

**模型底座与首版训练范围。**

沿用 Wan2.1 T2V，不切换到 I2VGen-XL。

首先确认项目使用的官方型号是 1.3B 还是 14B。若没有既定型号，优先用 1.3B 完成首轮可行性实验。正式对照组必须使用相同型号；不同规模的结果分别报告。

首版采用以下训练范围：

- 冻结 Wan-VAE、UMT5、视觉教师和光流模型。
- 训练新增 LRV 条件适配器。
- 使用固定范围的 LoRA 适配 Wan DiT。
- 对齐实验训练新增投影头。
- 参考实验额外训练 HRI 条件适配器。
- 保留 Wan 原有 Flow Matching 目标和时间参数约定。

LoRA 的目标层、秩、条件注入位置和精确对齐层索引，在预检阶段确定并写入配置；同一轮对照保持一致。

原生 Wan T2V 不等于视频超分模型。必须建立并训练能够读取 LRV 的条件通路。

这套系统的主数据流是：

LRV 经条件适配器、caption 经 UMT5、可选 HRI 经参考适配器，共同影响 Wan DiT。DiT 生成的 latent 经 Wan-VAE 解码为 HRV。

训练时，额外取出 DiT 中间特征，通过投影头与 HRV 教师特征进行比较。教师和关系监督通过损失反向影响可训练的生成模块。

**LRV 与 HRI 条件通路的具体安排。**

LRV 通路采用一个容易审计的起点：将 LRV 上采样到目标空间尺寸，经冻结 Wan-VAE 编码，再通过可训练条件 stem 和零初始化残差映射注入若干 DiT 层。所有对照使用相同注入结构。

HRI 通路在第二轮加入：将参考帧作为单帧视频经 Wan-VAE 编码，转换为参考 tokens，附带帧索引，通过参考 cross-attention 和残差门控影响生成过程。

训练参考模型时：

- 每段视频最多提供一张参考帧。
- 随机选择参考时刻，并记录其索引。
- 默认以 0.5 概率关闭参考条件。
- 无参考时明确关闭参考残差，不能仅用一张黑图冒充缺失条件。
- 各参考对照使用相同的参考采样与缺失策略。

主评估固定参考首帧，另用中间帧参考检查适应性。未知时刻或跨视频参考不属于首版任务。

**共享对齐空间怎样形成。**

固定教师提供参照空间，学生投影头与超分模型联合训练，不先单独训练一个新 autoencoder。

记：

- \(h_i\)：扩散网络在对应位置的中间特征；
- \(u_i=\operatorname{normalize}(P(h_i))\)：投影后的学生特征；
- \(v_i=\operatorname{normalize}(T(\mathrm{HRV})_i)\)：停止梯度的教师特征。

点式对齐目标为：

\[
\mathcal L_A
=
\operatorname{mean}_{i\in\mathrm{valid}}
\left(1-u_i^\top v_i\right).
\]

首轮只选一个教师、一个对齐层和一种投影结构。默认使用网络约三分之一深度附近、已受到 LRV 条件影响的隐藏特征，投影头采用 REPA 式轻量 MLP。

必须检查对齐损失能否传回 LRV 适配器或 LoRA。只有投影头学会拟合教师，而生成网络没有获得有效梯度，不构成有效实验。

**时空对应是独立的必做模块。**

Wan-VAE 会压缩时间和空间，DiT tokens 不能直接按原视频帧编号与教师特征配对。

首版固定一种明确方案：

- 从实际模型配置读取时间压缩步长和 token 网格。
- 在原视频中选择与 latent 时间位置对应的监督锚点，例如步长为 4 时使用 0、4、8 等帧。
- 从这些 HR 帧提取教师 patch 特征，并映射到学生空间网格。
- 对齐裁剪位置、缩放方式和有效区域，屏蔽 padding。
- 监督锚点表示指定的学习目标，不假定一个 latent token 只编码某一帧或互不重叠的四帧。

第一轮先固定这一方案。时间池化、可学习时间适配器等替代方案留作后续消融，避免同时改变多个因素。

**跨帧关系监督的具体定义。**

关系监督要求学生保持教师的关系结构。不能简单要求相邻帧特征相等。

首版建立两类边：

- 同一帧中相邻 patch 的空间关系。
- 相邻监督锚点之间，经运动补偿后对应区域的时间关系。

使用冻结光流模型，在相关 HRV 帧之间估计运动；通过前后向一致性、边界检查生成有效性权重。这里使用的是“从 HRV 估计的光流”，不是假定存在真实标注光流。

对于关系边 \((i,j)\)，比较学生和教师的余弦相似度：

\[
\mathcal L_R
=
\frac{
\sum_{(i,j)\in E}
w_{ij}
\left[
u_i^\top u_j-v_i^\top v_j
\right]^2
}{
\sum_{(i,j)\in E}w_{ij}+\epsilon
}.
\]

空间边和时间边分别归一化后组合。跨帧采样使用相同的运动映射处理学生和教师特征，并正确换算光流的空间尺度。

如果监督锚点相隔四帧，应估计这两个锚点之间的运动，不能直接套用原视频相邻帧光流。

HRV、教师特征和由 HRV 估计的光流均不进入推理条件。推理参考分支依靠实际输入学习信息交互。

**首版总损失和对照矩阵。**

\[
\mathcal L
=
\mathcal L_{\mathrm{FM}}
+
\lambda_A\mathcal L_A
+
\lambda_R\mathcal L_R.
\]

其中 \(\mathcal L_{\mathrm{FM}}\) 保留 Wan 原生定义。

| 对照 | 生成损失 | 点式对齐 | 关系监督 |
|---|---|---|---|
| Base | 有 | 无 | 无 |
| Align | 有 | 有 | 无 |
| Relation | 有 | 无 | 有 |
| Both | 有 | 有 | 有 |

这四组在无参考条件下完成第一轮；加入相同 HRI 分支后，再完成参考版本的四组。

参考版本的每个 checkpoint 都测试“提供 HRI”和“关闭 HRI”两种情况。无参考训练版本与参考缺失训练版本分别标明，不能混为同一种训练设置。

损失在有效位置上归一化。可将 0.1 作为新增权重的初始调试值，但正式权重需要依据验证集、损失尺度和梯度规模确定。搜索范围和预算提前记录，测试集不参与选择。首轮不同时探索多个教师、多层对齐或复杂时间权重。

**数据与评价协议。**

默认先研究固定 ×4 空间超分，不改变帧率。若实际数据任务指定其他倍率，在实验开始前统一修改。

按原视频划分训练、验证和测试集；同一视频的帧与相邻片段不得跨集合。caption 来源、参考帧选择、退化方式对所有对照一致。

数据实验分两层推进：

- 先用可控退化完成机制验证。
- 再引入模糊、噪声和视频压缩，测试未见退化和真实低清视频。

视频退化需要考虑时间一致性，不能默认每帧独立随机选择完全不同的退化参数。缓存必须绑定数据划分、裁剪、退化和版本信息，防止特征或光流错配。

有配对 HRV 的主指标为：

| 维度 | 指标或检查 |
|---|---|
| 保真度 | PSNR↑、SSIM↑ |
| 空间感知质量 | LPIPS↓ |
| 时间变化与运动保持 | tLP↓、tOF↓ |
| 参考传播效果 | 非参考帧收益，以及收益随距参考帧时间距离的变化 |
| 实际成本 | 推理耗时、峰值显存、训练 GPU 小时 |
| 条件使用情况 | 输出是否跟随 LRV 的对象、位置和运动；caption 是否被合理使用 |

真实无真值视频采用 MUSIQ 和视频盲评作为补充，分别判断清晰自然程度、输入内容保持、闪烁和拖影。

有参考实验的主恢复结果排除已提供的高清参考帧，并单独报告该帧表现。有／无参考的收益比较使用相同评价帧集合。主时间指标也明确是否排除了涉及参考帧的帧对。

固定评估预处理、采样步数、CFG、分辨率、帧数和预设随机种子。先按每段视频汇总，再跨视频平均。确认收益时使用多个采样种子，不挑最好样本；训练重复和采样重复分别标记。

共享空间的机制诊断另外报告：验证集对齐误差、对应区域匹配、关系误差、特征方差或有效秩，以及对生成模块的梯度。特征更聚集、对齐损失下降，都不能单独证明恢复有效或严格同胚成立。

**按以下阶段执行。**

1. **建立独立工程并完成预检。**  
   核实 GPU、显存、数据路径、官方权重型号和代码版本。确定统一配置，完成一次前向、反向和采样。检查时空索引、mask、条件输入和梯度路径；评估 HRV 经 VAE 编解码后的损失，了解压缩带来的影响。零初始化分支可在数个更新后检查梯度，避免误判首步的零梯度。

2. **建立并验证 Base。**  
   先在少量片段上验证训练闭环，再进行固定预算训练。检查相同 caption、不同 LRV 时输出是否跟随视频输入；关闭或打乱 LRV 条件时恢复是否明显受影响。保存上采样 LRV 作为简单参照。Base 必须能够执行视频恢复，不能只生成符合文本的新视频。

3. **验证点式对齐。**  
   从相同官方初始化独立训练 Align，与 Base 使用相同数据、生成网络训练范围和更新预算。检查恢复指标与收敛曲线，额外记录教师带来的训练成本。若仅投影损失改善，先排查对应与梯度，再通过验证集调整。

4. **验证关系监督。**  
   实现 Relation 与 Both，形成四组消融。重点检查非参考帧的 LPIPS、tLP、tOF，以及快运动、遮挡和细纹理视频。时间指标改善必须排除模糊化、静止化或改变输入运动造成的假象。

5. **加入可选 HRI。**  
   四组加入相同参考分支，从官方权重重新独立训练参考版本。比较有／无参考，检查信息是否传播到其他帧，以及关闭参考后能否稳定工作。

6. **完成泛化与最终报告。**  
   在未见退化、不同运动程度和真实低清视频上评价。对有效版本进行更多随机种子验证，报告质量、成本、失败案例和指标取舍。所有模块是否有效由实验决定，保留并报告负结果。

实施时先完成预检、Base 和 Align 的小规模验证，再扩展其他组，不直接启动全部完整训练。正式比较的初始化和预算规则始终保持一致。

**首版之外的扩展。**

Self-Flow 内部教师、无参考学生蒸馏、显式图文共享语义空间，以及新的可解码 universal latent，属于后续候选。它们不加入首轮主实验，以便先确定外部视觉对齐和关系监督是否有效。

- [Wan2.1 官方仓库](https://github.com/Wan-Video/Wan2.1)：模型、权重、VAE、文本条件及采样基础；需要实现任务专用的超分训练与条件模块。
