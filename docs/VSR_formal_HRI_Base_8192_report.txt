2. 次要ref4的PSNR+0.12807dB，32/32视频为正，SSIM也小增；LPIPS均值增加约0.001256，来源区间为正。tLP略降但区间跨零，tOF均值略升且区间跨零。小幅保真度收益伴随感知取舍，不能当作H3整体成立。
3. 分帧描述：主ref0在非参考帧1–7的PSNR均值变化约+0.001至+0.007dB，最后帧8约−0.0155dB；各帧LPIPS均值均略差。ref4在前后非参考帧均有约+0.118至+0.147dB的PSNR变化，LPIPS均值仍略差。它们是全部视频/两种子的均值描述，没有按好例挑选或做逐帧显著性结论。
4. 当前证据仅来自一次训练及固定内部val32；来源bootstrap不含训练种子不确定性，无多重比较校正，LPIPS主项区间下界尤其接近零。采样种子42/43不是训练重复。
5. 参考来自同一配对视频、已知位置且空间裁剪一致；9帧覆盖33源帧，远离首帧的最大距离约1.07–1.33秒。它不证明长视频、任意外部参考图或真实未知退化泛化。HRI辅助A/R隔离诊断将在参考矩阵完成、GPU空闲后执行；Base本身没有A/R投影头。
